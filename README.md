# Global Maternal and Child Health Inequality Analysis

## About
This project explores global inequality in maternal and child health using World Bank data, and asks whether better access to skilled care is linked to lower mortality.

## Research Question
Is higher skilled birth attendance associated with lower maternal and child mortality?

## Data
Source: World Bank
- Under-5 mortality rate (per 1,000 live births)
- Maternal mortality ratio
- Births attended by skilled health staff (% of total)

Coverage: 193 countries, 1985-2023

## Methods
- Tool: R (tidyverse)
- Data cleaning, reshaping and joining datasets
- Scatter plots and line graphs
- Simple linear regression

## Key Findings
- Under-5 and maternal mortality are strongly correlated (r = 0.879).
- Higher skilled birth attendance is associated with lower maternal mortality (R-squared = 0.65).
- Bangladesh reduced under-5 mortality by about 87.6% between 1985 and 2023.

## Limitations
This is an observational analysis. It shows association, not causation.
